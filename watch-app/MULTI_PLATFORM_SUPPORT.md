# 多平台支持说明

本应用现已支持多个手机平台，包括**鸿蒙**、**安卓**、**小米澎湃系统（HyperOS）**，并特别优化了小米智慧中心接入。

## 🌐 支持的平台

### 1. 鸿蒙系统（HarmonyOS）

**支持设备**：
- 华为 GT5 手表
- 华为 Watch 系列
- 其他支持 HarmonyOS 的智能手表

**支持手机**：
- 华为、荣耀等搭载鸿蒙系统的手机

**工作原理**：
- 利用 HarmonyOS 的通知同步机制
- 手表自动接收手机端的高德地图通知
- 无需手机端额外开发

**配置步骤**：
1. 确保手机与手表已配对
2. 在华为运动健康 App 中开启"通知提醒"
3. 确保高德地图的通知权限已开启
4. 在手表设置中授予应用"通知访问权限"

### 2. 安卓系统（Android）

**支持设备**：
- Wear OS 智能手表
- 其他支持 Android Wear 的手表
- 华为 GT5（配对 Android 手机时）

**支持手机**：
- Android 8.0+ 系统的手机

**工作原理**：
- 使用 Android NotificationListenerService
- 监听系统通知栏的高德地图通知
- 通过 Wear OS Data Layer 同步数据

**配置步骤**：
1. 确保手机与手表已通过蓝牙配对
2. 安装 Wear OS App（如需要）
3. 在 Android 设置中授予应用"通知访问权限"：
   - 设置 → 应用 → 特殊应用权限 → 通知访问权限
   - 找到"高德导航"并开启
4. 确保高德地图的通知权限已开启

### 3. 小米澎湃系统（HyperOS）⭐

**支持设备**：
- 华为 GT5（配对小米手机时）
- 其他支持多平台的智能手表

**支持手机**：
- 小米、Redmi 搭载 HyperOS 的手机
- MIUI 14+ 系统的小米手机

**特色功能**：
- ✨ **小米智慧中心接入** - 获得更好的数据同步体验
- ✨ **更低延迟** - 通过小米 IoT 生态优化
- ✨ **更稳定的连接** - 利用小米智慧中心的设备互联

**工作原理**：
- **优先方式**：通过小米智慧中心（Xiaomi AI Hub）接收导航数据
- **备用方式**：通知监听（与 Android 相同）
- 自动检测小米智慧中心是否可用，智能切换

**配置步骤**：

#### 方式一：使用小米智慧中心（推荐）

1. **在小米手机上：**
   - 打开"小米智慧中心" App
   - 添加华为 GT5 手表到设备列表
   - 授予必要权限（设备互联、数据访问）

2. **在手表上：**
   - 打开"高德导航"应用
   - 应用会自动检测到小米智慧中心
   - 显示"支持小米智慧中心，获得更好体验"

3. **测试连接：**
   - 在手机上启动高德地图导航
   - 手表应立即显示导航信息
   - 延迟通常 < 200ms

#### 方式二：使用通知监听（备用）

如果小米智慧中心不可用，应用会自动降级到通知监听模式：

1. 在小米手机设置中授予"通知访问权限"
2. 确保蓝牙连接正常
3. 其他步骤与 Android 相同

## 🔧 小米智慧中心集成详解

### 什么是小米智慧中心？

小米智慧中心（Xiaomi AI Hub）是小米 IoT 生态的核心服务，提供：
- 设备间数据互通
- 智能场景联动
- 低延迟数据传输
- 统一的设备管理

### 接入优势

1. **更低延迟**
   - 直接通过 IoT 协议传输
   - 无需经过通知系统
   - 延迟降低 60%+

2. **更稳定**
   - 专用数据通道
   - 自动重连机制
   - 更好的网络适应性

3. **更智能**
   - 支持场景联动
   - 可与其他小米设备协同
   - 未来可扩展更多功能

### 技术架构

```
┌──────────────────────────────┐
│      小米手机                 │
│  ┌────────────────────────┐  │
│  │    高德地图             │  │
```

## 🔍 故障排查

### 鸿蒙系统问题

**问题：手表收不到导航信息**
- 检查华为运动健康中的通知同步设置
- 确认高德地图通知权限已开启
- 检查手表与手机的连接状态
- 重启手表应用

### 安卓系统问题

**问题：通知访问权限无法授予**
- 进入设置 → 应用 → 特殊应用权限
- 找到"通知访问权限"
- 手动开启"高德导航"应用的权限

**问题：数据延迟较高**
- 检查蓝牙连接质量
- 确保 Wear OS 服务正常运行
- 尝试重启蓝牙连接

### 小米澎湃系统问题

**问题：小米智慧中心无法连接**
1. 检查小米智慧中心 App 是否已安装
2. 确认已将手表添加到设备列表
3. 检查必要权限是否已授予
4. 尝试重启小米智慧中心服务

**问题：智慧中心连接后仍无数据**
- 应用会自动降级到通知监听模式
- 检查通知访问权限
- 查看日志确认降级原因

**问题：如何确认使用的是智慧中心还是通知监听？**
- 查看应用启动时的提示信息
- 智慧中心模式会显示："支持小米智慧中心，获得更好体验"
- 通知监听模式会显示："使用通知监听"
- 也可在日志中查看：`[HyperOS] INFO: 使用小米智慧中心接收导航数据`

## 💡 使用建议

### 对于鸿蒙用户
- 保持系统和应用更新到最新版本
- 确保通知同步功能正常
- 建议使用华为/荣耀手机获得最佳体验

### 对于安卓用户
- 确保 Wear OS 服务正常运行
- 定期清理系统缓存
- 避免使用过于激进的省电模式

### 对于小米用户
- **强烈推荐**使用小米智慧中心
- 将手表添加到常用设备，避免被清理
- 开启"设备互联"功能获得更好体验
- 配合小米手环、音箱等设备可实现场景联动
