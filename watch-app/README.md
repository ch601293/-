# 高德地图导航手表应用

这是一个使用仓颉语言开发的华为 GT5 手表应用，可以实时显示手机上高德地图的导航内容。

## 功能特性

- ✅ **实时导航显示**：在手表上实时显示导航指令、距离和道路信息
- ✅ **智能通知监听**：自动监听高德地图的导航通知，无需手机端额外开发
- ✅ **蓝牙通信支持**：支持通过蓝牙与手机端通信（可选功能）
- ✅ **友好的UI界面**：专为手表圆形屏幕优化的导航显示界面
- ✅ **多种导航类型**：支持直行、左转、右转、掉头、环岛等各种导航指令
- ✅ **剩余信息显示**：显示剩余距离、预计时间等信息

## 工作原理

本应用采用**通知监听**的方式实现导航信息的获取，工作流程如下：

1. **手机端**：用户在手机上启动高德地图并开始导航
2. **通知同步**：高德地图的导航通知通过 HarmonyOS 自动同步到手表
3. **通知监听**：手表应用监听到高德地图的通知
4. **数据解析**：从通知内容中解析出导航指令、距离、道路等信息
5. **界面显示**：在手表屏幕上以友好的方式显示导航信息

### 优势

- **无需手机端开发**：充分利用 HarmonyOS 的通知同步机制，手机端只需正常使用高德地图即可
- **低功耗**：基于系统通知机制，不需要持续的蓝牙数据传输
- **兼容性好**：适用于所有版本的高德地图

## 环境要求

- **开发环境**：DevEco Studio 4.0 或更高版本
- **编程语言**：仓颉语言（Cangjie）
- **操作系统**：HarmonyOS 3.0 或更高版本
- **目标设备**：华为 GT5 手表（或其他支持 HarmonyOS 的智能手表）
- **手机系统**：HarmonyOS 3.0+ 或 Android 8.0+（需支持通知同步）

## 安装步骤

### 1. 开发环境配置

1. 下载并安装 [DevEco Studio](https://developer.harmonyos.com/cn/develop/deveco-studio)
2. 安装仓颉语言插件
3. 配置 HarmonyOS SDK

### 2. 项目构建

```bash
# 克隆项目
git clone <repository-url>
cd watch-app

# 使用 DevEco Studio 打开项目
# 或使用命令行构建
hvigorw assembleHap
```

### 3. 安装到手表

#### 方法一：通过 DevEco Studio

1. 连接华为 GT5 手表到电脑（通过蓝牙或 USB）
2. 在 DevEco Studio 中点击 "Run" 按钮
3. 选择目标设备（华为 GT5）
4. 等待应用安装完成

#### 方法二：通过 hdc 命令行

```bash

hdc list targets

# 安装应用
hdc install entry-default-signed.hap

# 启动应用
hdc shell aa start -a NavigationWatchApp -b com.huawei.amap.navigation.watch
```

## 使用说明

### 首次使用配置

1. **安装应用**：将应用安装到华为 GT5 手表

2. **授予权限**：
   - 打开手表上的应用
   - 系统会提示授予"通知访问权限"
   - 进入设置 → 通知 → 通知访问权限
   - 找到"高德导航"并开启权限

3. **配置手机通知同步**：
   - 确保手机与手表已配对连接
   - 在华为运动健康 App 中开启"通知提醒"功能
   - 确保高德地图的通知权限已开启

### 日常使用

1. **启动导航**：
   - 在手机上打开高德地图
   - 输入目的地并开始导航

2. **查看手表**：
   - 打开手表上的"高德导航"应用
   - 手表会自动显示导航信息
   - 包括：导航方向、距离、道路信息等

3. **导航过程中**：
   - 手表会实时更新导航信息
   - 跟随高德地图的导航指令同步显示
   - 可以抬腕查看，无需拿出手机

4. **结束导航**：
   - 在手机上结束导航后
   - 手表会显示"导航已结束"或"已到达目的地"

## 核心功能说明

### 1. 导航数据模型 (NavigationData.cj)

定义了导航数据的结构，包括：
- 导航指令（如"前方500米左转"）
- 导航类型（直行、左转、右转等）
- 距离信息
- 道路名称
- 剩余距离和时间
- 当前速度

### 2. 通知监听服务 (NotificationListener.cj)

核心功能模块，负责：
- 监听系统通知
- 筛选高德地图的导航通知
- 触发导航数据解析
- 通知UI更新

### 3. 导航数据解析器 (NavigationParser.cj)

智能解析模块，能够：
- 从通知文本中提取导航信息
- 识别导航类型（左转、右转等）
- 解析距离数据（支持米、公里等单位）
- 提取道路名称
- 计算剩余信息

### 4. 导航显示界面 (NavigationView.cj)

用户界面组件，提供：
- 清晰的导航方向图标
- 大字体距离显示
- 导航指令文本
- 道路信息
- 剩余距离和时间

### 5. 蓝牙通信服务 (BluetoothService.cj)

可选的扩展功能：
- 支持手表与手机的蓝牙通信
- 可用于传输更详细的导航数据
- 提供连接状态管理

## 常见问题

### Q1: 手表上没有显示导航信息？

**解决方法**：
1. 检查手表是否授予了通知访问权限
2. 确认手机与手表已正确配对
3. 检查手机上高德地图的通知权限是否开启
4. 确认华为运动健康 App 中的通知同步功能已开启

### Q2: 导航信息更新不及时？

**解决方法**：
1. 检查手机与手表的蓝牙连接状态
2. 确认手机网络连接正常
3. 尝试重启手表应用

### Q3: 部分导航指令无法识别？

**解决方法**：
- 这可能是导航解析器的关键词库不完整
- 可以在 `NavigationParser.cj` 中添加更多关键词
- 欢迎提交 Issue 反馈未识别的导航指令

### Q4: 手表耗电较快？

**解决方法**：
1. 本应用基于通知监听，功耗较低
2. 确保在不需要时关闭应用
3. 可以设置手表屏幕自动息屏时间

### Q5: 支持其他导航应用吗？

**解决方法**：
- 目前仅支持高德地图
- 可以修改 `Constants.cj` 中的包名常量来适配其他应用
- 需要根据不同应用的通知格式调整解析逻辑

## 技术特点

### 使用仓颉语言的优势

1. **性能优秀**：仓颉语言编译为原生代码，运行效率高
2. **类型安全**：强类型系统减少运行时错误
3. **内存安全**：自动内存管理，避免内存泄漏
4. **并发支持**：原生支持并发编程
5. **HarmonyOS 集成**：与 HarmonyOS SDK 深度集成

### 架构设计

- **分层架构**：Model-Service-UI 三层架构
- **低耦合**：各模块职责明确，易于维护和扩展
- **事件驱动**：基于通知和回调的事件驱动模型
- **资源优化**：针对手表设备的低功耗和小屏幕优化

## 开发扩展

### 添加新的导航类型

在 `NavigationData.cj` 中添加新的枚举值：

```cangjie
public enum NavigationType {
    | STRAIGHT
    | LEFT_TURN
    // ... 现有类型
    | YOUR_NEW_TYPE  // 添加新类型
}
```

### 自定义 UI 样式

修改 `NavigationView.cj` 中的样式常量：

```cangjie
// 修改字体大小
text.setTextSize(YOUR_FONT_SIZE)

// 修改颜色
text.setTextColor(Color(YOUR_COLOR))
```

### 支持其他地图应用

修改 `Constants.cj` 中的包名配置：

```cangjie
public static let AMAP_PACKAGE_NAMES: Array<String> = [
    "com.autonavi.minimap",        // 高德地图
    "com.your.map.package"         // 添加其他地图包名
]
```

然后调整 `NavigationParser.cj` 中的解析逻辑以适配新的通知格式。
