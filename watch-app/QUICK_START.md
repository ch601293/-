# 快速开始指南

本指南将帮助您快速上手使用高德地图导航手表应用。

## 前提条件

- ✅ 华为 GT5 手表（或其他支持 HarmonyOS 的智能手表）
- ✅ 华为手机或支持通知同步的 Android 手机
- ✅ 已安装高德地图 App
- ✅ 手机与手表已配对连接

## 5分钟快速配置

### 第一步：安装应用

1. 下载应用安装包 `navigation-watch-app.hap`
2. 通过华为应用市场或 DevEco Studio 安装到手表
3. 在手表上找到并打开"高德导航"应用

### 第二步：授予权限

**在手表上操作：**

1. 首次打开应用时，系统会提示授予权限
2. 点击"设置" → "通知" → "通知访问权限"
3. 找到"高德导航"应用，开启权限
4. 返回应用

**重要**：通知访问权限是应用正常工作的必要条件！

### 第三步：配置通知同步

**在手机（华为运动健康 App）上操作：**

1. 打开"华为运动健康" App
2. 进入"设备" → 选择您的手表
3. 点击"通知提醒"
4. 确保"通知提醒"开关已开启
5. 找到"高德地图"，确保其通知同步已开启

### 第四步：测试导航

1. **在手机上打开高德地图**
2. **输入一个目的地并开始导航**
3. **查看手表**：
   - 打开手表上的"高德导航"应用
   - 应该能看到导航信息显示

## 使用技巧

### 技巧 1：抬腕查看

- 在导航过程中，只需抬起手腕即可查看导航信息
- 无需拿出手机，更加安全便捷

### 技巧 2：省电模式

- 查看完导航后，放下手腕让屏幕自动熄灭
- 应用在后台继续工作，但不会持续点亮屏幕

### 技巧 3：切换应用

- 即使切换到其他应用，导航信息也会继续更新
- 需要查看时再切换回来即可

## 故障排查

### 问题：手表上没有显示导航

**检查清单：**
- [ ] 手表应用是否已打开
- [ ] 是否授予了通知访问权限
- [ ] 手机与手表是否已连接
- [ ] 手机上高德地图是否正在导航
- [ ] 手机上高德地图的通知权限是否开启
- [ ] 华为运动健康中的通知同步是否开启

**解决步骤：**
1. 确认以上所有项都已正确配置
2. 尝试重启手表应用
3. 尝试重启手表蓝牙连接
4. 如仍无法解决，查看详细的 [README.md](README.md)

### 问题：导航信息不更新

**可能原因：**
- 手机网络断开
- 手表与手机失去连接
- 高德地图已停止导航

**解决方法：**
1. 检查手机网络连接
2. 检查手表蓝牙连接状态
3. 在手机上确认导航是否仍在进行

### 问题：手表耗电快

**优化建议：**
1. 不使用时关闭应用
2. 设置合适的屏幕自动熄灭时间
3. 关闭不必要的通知同步
